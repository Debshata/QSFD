# Final Report — Content Draft

**Status: CREATED.** Two reference format documents were supplied (`IEEE-Format (1).docx` and
`Springer_Paper_Format_Doc.docx`). The IEEE two-column conference format was selected as the more standard format
for a technical/engineering capstone report of this kind. The final report was generated by
`scripts/reports/build_final_report.py`, which opens the IEEE reference template, reuses its exact paragraph
styles (title, author, abstract, heading levels 1-3, figure/table captions, reference-item style) and page/column
layout, clears the template's own instructional example content, and writes real project content into those
styles — saved as `Quantum_Secure_Fraud_Detection_System_Final_Report.docx` at the repository root. The reference
template file itself was never modified (verified: only read via `Document()`, saved to a different path).
A Springer/LNCS-format version was not additionally generated in this round; the same `reports/materials/`
content could be poured into that template's styles the same way if the Springer format is preferred instead.
