# QSFD LaTeX report package

| Target | Root file | Class | Notes |
|---|---|---|---|
| University project report (complete) | `university/main.tex` | `report` | Planning chapters, literature review, evidence map, technical chapters, IBM hardware chapter, appendices; TOC/LoF/LoT are generated by LaTeX |
| IEEE paper (concise) | `ieee/main.tex` | `IEEEtran` (official, `[conference]`) | Shares the technical sections with the other targets |
| Springer paper (concise) | `springer/main.tex` | `llncs` (official, `runningheads`) | **Requires** `llncs.cls` and `splncs04.bst` from Springer's LNCS author kit placed in `springer/` (not redistributed or modified here) |

## Single source of truth
`results/final/final_results.json` is generated from the saved result artifacts (`scripts/final/build_final_results.py`).
`scripts/final/build_latex_assets.py` turns it into `common/generated/results_macros.tex` (every headline number is a macro such as `\LsDelta`), generated tables in `common/tables/` and copies of the figures in `common/figures/`.
Prose never types a headline number by hand, so the three documents cannot disagree. Shared text lives in `common/paper/*.tex`; the university report adds its planning chapters in `university/sections/`.

```bash
python scripts/final/build_final_results.py --junit <pytest junit xml>
python scripts/final/build_latex_assets.py
python scripts/final/check_latex.py      # static checks: inputs, labels, citations, macros, figures (not a compile)
```

## Compiling (Overleaf Workshop in VS Code or local TeX)
Open the `report/` folder as the project root in Overleaf Workshop (or upload it to Overleaf), select the target's `main.tex` as the root document and compile with pdfLaTeX + BibTeX (two further passes resolve the TOC and references). Keep the folder layout: the documents refer to `../common/...`.
